# Pokemon App

Aplicação interativa de busca e visualização de Pokémon com React, TypeScript e Vite. Explore Pokémon por tipo, compare stats, veja evoluções e muito mais!

## Funcionalidades

- Busca de Pokémon por nome ou número
- Filtro por tipo (Fire, Water, Grass, etc.)
- Modal com detalhes completos (stats, habilidades, evoluções)
- Comparação lado a lado de Pokémon
- Calculadora de efetividade de tipos
- Sistema de favoritos
- Modo escuro/claro
- Design responsivo

## Tecnologias

- **React 18** - Biblioteca de interfaces
- **TypeScript** - Tipagem estática
- **Vite** - Build e dev server
- **Tailwind CSS** - Estilização utilitária
- **PokéAPI** - Dados dos Pokémon

## Como Executar

git clone https://github.com/RFernandes10/pokemon-app.git
cd pokemon-app
npm install
npm run dev

Acesse http://localhost:5173
